# ТЗ: персональное приложение для расширения словарного запаса (Android)

## 1. Цель
Личное приложение для русскоязычного ученика уровня B1–C1. Главная задача: быстро расширять активный словарный запас и фразы. Вторично: грамматика, произношение, разговорные фразы (этапы 2–3).

## 2. Ограничения
- Только для личного использования: APK ставится вручную, без Google Play, без аккаунтов и серверной части.
- ИИ-функции работают через любой провайдер с OpenAI-совместимым API (`POST {baseUrl}/chat/completions`). Модель и провайдер задаются в настройках. Привязки к конкретной модели нет.
- Ключ API хранится только на устройстве (SharedPreferences) и никогда не попадает в репозиторий.
- Приложение работает офлайн; ИИ нужен только для мнемоник, перевода новых слов и генерации контента.

## 3. Функции этапа 1 (MVP, входит в текущую сборку)
1. **Занятие**: очередь = просроченные повторения + до 15 новых слов. Карточка: слово, по нажатию — перевод, пример, озвучка (системный TTS en-US), кнопка «Мнемоника (ИИ)».
2. **Оценка**: четыре кнопки — Снова / Трудно / Хорошо / Легко. Алгоритм SM-2 (упрощённый).
3. **Добавление слова**: вручную (слово + перевод) или с заполнением через ИИ (перевод, пример, тип «слово/фраза»).
4. **Мнемоники**: ИИ генерирует ключевое слово (созвучие), образ, этимологию; результат сохраняется в карточке.
5. **Стартовая база**: 2000 слов и фраз из `assets/seed.json`, генерируется скриптом `tools/gen_seed.py`. Если файла нет, загружается `assets/starter.json` (30 записей).
6. **Настройки ИИ**: baseUrl, API-ключ, модель. Примеры адресов даны в экране.
7. **Статистика на главном экране**: всего слов, новых, на повтор сейчас.

## 4. Этапы 2–4 (не в текущей сборке)
- Этап 2: чтение текста с нажатием по слову, импорт CSV, коллокации и фразовые глаголы как отдельный фильтр, экран «Трудные» (частые ошибки), экспорт/импорт резервной копии JSON.
- Этап 3: произношение (запись голоса, сравнение с эталоном, минимальные пары), shadowing, разговорный ИИ-партнёр с разбором ошибок.
- Этап 4: грамматическая диагностика по ошибкам, проверка собственных текстов, письменные упражнения, предложения «составь предложение со словом».

## 5. Модель данных (карточка)
`id, en, ru, example, kind (word|phrase), mnemonic, ease, interval (дни), reps, lapses, due (epoch ms)`.
Новая карточка: `reps == 0 && lapses == 0 && interval == 0`.

## 6. Алгоритм повторений
- Оценка «Снова» (q=1): lapses+1, reps=0, интервал 1 день, повтор через 10 минут.
- Оценка «Трудно/Хорошо/Легко» (q=3/4/5): reps+1. Интервалы 1 → 3 → interval × ease. «Трудно» ×0.7, «Легко» ×1.3 +1.
- Ease: `ease += 0.1 − d·(0.08 + 0.02·d)`, d = 5 − q, минимум 1.3.

## 7. Экраны
Главный, Занятие, Добавить слово, Настройки ИИ. Интерфейс на русском, учебный контент на английском.

## 8. Сборка
- Исходники в GitHub-репозитории. При каждом push в `main` GitHub Actions собирает release APK и выкладывает его как artifact (`english-trainer-apk`).
- Если папки `android/` нет, workflow создаёт её через `flutter create`.
- Установка: скачать artifact, перенести APK на телефон, разрешить установку из неизвестных источников.

## 9. Критерии приёмки этапа 1
- APK собирается в GitHub Actions без ошибок.
- При первом запуске в базе ≥ 30 слов (starter) или ≥ 1500 (после генерации seed).
- Занятие проходит очередь, интервалы растут после «Хорошо» и сбрасываются после «Снова».
- Данные сохраняются после перезапуска приложения.
- Мнемоника и заполнение через ИИ работают с любым OpenAI-совместимым провайдером; при ошибке показывается текст ошибки, приложение не падает.
- Ключ API не виден в репозитории и в коде.
